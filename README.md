SismoAlert
  Sistema de monitoreo sísmico con Inteligencia Artificial.

Características
  .IA: Predicción de magnitud probable mediante Random Forest.
  .Backend: API construida con FastAPI.
  .Base de Datos: Historial almacenado en SQLite.
  .Frontend: Mapa interactivo con Leaflet.js.

Instalación
  1- pip install -r requirements.txt
  2- uvicorn main:app --reload
